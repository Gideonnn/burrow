Mail · ontwerp v3

Nieuw: server en client zijn gescheiden. De server draait op een kleine computer in de meterkast en doet sync, agent en MCP. De Mac-app is een client die verbindt met een API-sleutel, en elke sleutel ziet alleen de mailboxen die erbij horen. Zo kan de mail van je vriendin (hier "Eva", een voorbeeldnaam) erbij zonder dat jullie elkaars mail zien. Het overzicht schuift naar later. Wissel hieronder van sleutel om te zien wat elk apparaat ziet. Eerdere versies: v1.html, v2.html.

Personen, sleutels en mailboxen

Een persoon heeft eigen mailboxen, eigen agentinstructies en een eigen controlelijst. Een sleutel hoort bij één persoon en kan worden beperkt tot een deel van diens mailboxen en rechten. Een mailbox kan ook bij twee personen horen, bijvoorbeeld een gezamenlijk adres.

Regels die de server afdwingt

  • Een sleutel ziet niets buiten zijn mailboxen: niet in de lijst, niet in zoeken, niet in tellers, niet via MCP en niet in het agentlogboek.
  • "Beheer" mag accounts en sleutels toevoegen en intrekken. Alleen jouw hoofdsleutel heeft het.
  • Een sleutel zie je één keer; de server bewaart alleen de hash. Intrekken werkt direct, ook voor open verbindingen.
  • Agentinstructies, geleerde regels en Gefilterd horen bij de persoon. Eva's agent leest jouw instructies niet.

Hardware voor de meterkast

  • Advies: een mini-pc met een Intel N100 en 16 GB geheugen (rond € 150, ongeveer 8 watt). Een Raspberry Pi 5 met 8 GB kan ook, maar is krapper als Claude Code en de sync tegelijk draaien.
  • Linux met Docker Compose: één container voor de server, Tailscale op de host.
  • Elke nacht een versleutelde back-up van de database naar je NAS of een cloudopslag.
  • Claude Code log je één keer in op de server; de triage draait daarna headless (zonder venster).

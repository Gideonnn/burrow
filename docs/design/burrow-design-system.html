The Burrow family

One design language for a household's own office suite: separate native macOS apps (Hedwig for mail, Pensieve for meetings, more to follow) that share one server, one set of people and one team of AI workers. Documentation is in English; everything a person sees in the apps is Dutch.

20 October 2026·macOS 26, SwiftUI, SF Pro, SF Symbols·Names only: no Harry Potter artwork, fonts or quotes

v1 by Fable; v2 aligns shortcuts with the apps (⌘N records, ⌘. stops), adds agents on the Mac (5.x) and uses invented people throughout.

1Principles

Six rules that every screen in every Burrow app follows. When a decision is hard, the earlier rule wins.

Calm by default

A home, not a dashboard. Few colours, generous whitespace, no counters that shout. Notification badges count only what needs a person; a worker finishing quietly is not news.

Inbox badge shows "3", not "3 new, 14 filtered, 2 running".

Native first

SwiftUI controls, system fonts, SF Symbols, the standard sidebar, toolbar and settings window. Custom UI only where macOS has nothing: the worker card, the recording control, the waveform.

If a control exists in Apple Mail or Voice Memos, it looks the same here.

Workers propose, people decide

Every automated action shows who did it (the bot), why (one checkable sentence) and how to undo it. Sending mail, deleting and paying are never a bot's call.

"Kreacher: nieuwsbrief zonder afmeldlink, eerder door jou gearchiveerd." with Klopt / Terug.

Private unless shared

Content belongs to one person. Shared items carry a visible "Gedeeld" badge with the other person's avatar. An admin can change settings, never read content. The UI says this where it matters.

Settings › Huishouden: "Je kunt Eva's instellingen wijzigen, haar mail en opnames niet lezen."

Household scale

Two people, a handful of devices, a few bots. No teams, roles matrices or org charts. Names and faces instead of IDs; two person colours instead of a palette generator.

Owner marker is an initial in Ink (Gideon) or Heather (Eva), never a UUID.

Persona with a light touch

Bots have a name, a small monochrome mark and a one-line character. Persona shows in the label, never in the data: reasons and results are factual and plain.

Kreacher grumbles in his profile card; his filter reasons never do.

2Brand and colour

The Burrow is a crooked, cosy house. The palette is warm plaster, brick and old wood: neutrals with a hint of warmth, one brick accent for the platform, and a restrained signature colour per application and per person. Everything stays within what macOS itself would do: tinted selection, coloured sidebar icons, a few badges.

Usage rules

Tints

A tint is the colour at 12% (light) or 16% (dark) over the surface, used for badge backgrounds, reason cards and selected-but-inactive rows. Text on a tint always uses the full colour, never white.

One accent per window

The app colour drives selection, sidebar icons, toggles, links and the progress bar. Hearth appears inside an app only in platform sheets (login, household, workers). Person colours appear only in avatars and ownership markers. Semantic colours only mean what they say.

Dark mode

Dark surfaces stay warm (#1C1A17, not pure grey). Accents become lighter and slightly desaturated so they sit on dark backgrounds as text; filled buttons then use dark text (Soot) on the accent.

Shadows are warm (Soot at low alpha) and always paired with a 1 px hairline ring so cards hold up on Plaster. Level 0 is a hairline only (lists, settings groups). Toolbar buttons use the macOS 26 glass: translucent surface, hairline, 1 px drop.

Motion

  • State changes (toggle, selection, hover): 150 ms, ease-out.
  • Sheets and popovers: the system spring; never a custom curve.
  • Worker status: a status pill cross-fades; no confetti, no bouncing.
  • Live level meters: 60 fps from the audio callback, 20 ms attack, 300 ms release, peak hold 1 s.
  • Waveform playhead moves linearly; seeking jumps without animation.
  • Honour Reduce Motion: meters still move (they are information), everything else cuts.

Iconography: SF Symbols per concept

Always the SF Symbol, always monochrome in the current tint; hierarchical rendering for sidebar icons, filled variants only for the selected tab. The drawings in this document are stand-ins with the same silhouette.

Construction

1024 pt canvas, macOS squircle mask. Glyph fits a 600 pt box centred; stroke 64 pt (3 pt at 48). Fill: vertical gradient from the colour lightened 10% to the colour; a 22% white top-light at 160 degrees.

Menu bar and sidebar

In the menu bar the glyph is drawn as a template image (monochrome) at 18 pt. In sidebars and the launcher the 16 pt glyph is tinted in the app colour, no tile.

Bots

Bots do not get tiles. A bot is a monochrome mark in a rounded square with a hairline (see Avatars): Kreacher has pointed ears and a flat mouth, Winky has rounder ears and a neutral mouth. They are shapes, not characters from any film.

5Components

Everything is a system control first; the classes here describe how it is configured. Each specimen shows its states. Click toggles, segmented controls and tabs: they work.

Buttons

One primary per surface. Destructive actions are red text in a normal button; filled red only inside a confirmation. Disabled is 45% opacity, never a different colour. Keyboard focus is a 3 px ring in the accent at 45%.

Agents on the Mac

Claude Code or Codex on the person's Mac operate every running app through burrowctl and its MCP tools: read what is on screen, open things, prepare a draft and show it, change the person's own settings. Some buttons are the person's alone. Pressing one from an agent opens this dialog; the agent cannot see or press it, and the safe answer is the default.

What the launcher is

A menu bar item in Hearth, present on every Mac that has at least one Burrow app. It shows one line per application (the number that needs a person, never the total), what the workers are doing right now, and the server's health. Each tile opens the app; the Workers section opens Settings › Workers.

What it is not

Not a dashboard with charts, not a notification centre. If something needs attention it gets a count; if something broke it gets one red line with one action. The launcher is also the window that appears when a Burrow app is installed but not yet logged in.

Later

The same list as a Raycast extension (Accio) and as the first message Patronus sends in the morning (Daily Prophet). Same data, three surfaces.

Mail · ontwerp v1

Een lichte mailclient in de stijl van Apple Mail, met een agent die elke nieuwe mail sorteert, spam wegfiltert en antwoorden voorstelt. Klik door de schermen hieronder: het venster is interactief (berichten, suggesties, zijbalk, knoppen). Onderaan staan de keuzes waarop we itereren, met mijn advies voorgevinkt.

Hoe het in elkaar zit

Eén lokaal achtergrondproces (de daemon) doet het echte werk. De vensters zijn een dunne schil eromheen, zodat we die later native kunnen maken zonder de rest opnieuw te bouwen.

Gmail ─┐ ┌──────────────────────────────────────────────┐ Outlook ┼── IMAP + IDLE ───▶ │ mail-daemon (lokaal, draait ook zonder venster) │ Fastmail┘ (pushmeldingen) │ · sync naar SQLite (berichten, labels, log) │ │ · triage-wachtrij voor nieuwe mail │ │ · MCP-server (stdio + localhost-HTTP) │ └──────┬───────────────┬───────────────┬────────┘ │ │ │ ┌────────────────────────┘ │ └──────────────────────┐ ▼ ▼ ▼ Venster (Tauri, later native) Triage-agent: claude -p --model haiku Jouw agents via MCP leest dezelfde database (of codex exec), met jouw abonnement Claude Code, Codex en en alleen de mail-tools elke T3-thread ▲ "Bespreek in T3": de daemon maakt via de │ T3-server een thread met de mail als ────────┘ context, ook bereikbaar vanaf je telefoon

Wat erin zit en wat niet

Het doel is je primaire mailprogramma, dus de basis moet compleet zijn. Al het andere laten we weg tot je het mist.

Wel

  • Eén gezamenlijke inbox voor Gmail, Outlook en Fastmail
  • Lezen, beantwoorden, doorsturen, archiveren, verwijderen, concepten
  • Bijlagen bekijken en bewaren; versturen met bijlage
  • Zoeken in gewone taal, ook via je agents
  • Externe afbeeldingen standaard geblokkeerd (trackers), per afzender toestaan
  • Meldingen alleen voor mail met "Antwoord nodig"
  • Toetsenbordbediening zoals Apple Mail (j/k, e = archiveren, r = antwoorden)
  • Agent: spam, nieuwsbrieven, labels, samenvattingen, antwoordvoorstellen, activiteitenlog met terugdraaien

Niet (bewust)

  • Regels en filters bouwen: vervangen door instructies in gewone taal
  • Vlaggen, eigen mappen, slimme mappen, VIP's: "Antwoord nodig" + Archief + zoeken
  • Opmaakbalk in het opstelvenster: platte tekst met links
  • Agenda, contacten-app, sjablonen, gepland versturen, mail merge
  • Plug-ins, thema's, meerdere vensters per bericht
  • Agent die zelf verwijdert of verstuurt: kan technisch niet (zie keuze 3)
